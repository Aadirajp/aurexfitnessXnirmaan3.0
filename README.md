# Aurex Fitness Club Website

A responsive, multi-page fitness club website built with pure HTML5 and CSS3.

## Pages
- **Home (`index.html`)**: Hero section with cinematic background video, About section, and featured Training Programs.
- **Gallery (`gallery.html`)**: High-definition photo showcase categorized into Gym Facilities, Luxury Amenities, and Training Programs.
- **Pricing (`pricing.html`)**: Membership plans (Basic, Pro, Elite) displayed in Indian Rupees (₹) with feature checklists.

## Features
- Pure HTML & CSS (No external frameworks or complex JavaScript).
- Fixed transparent navigation bar with smooth scrolling and page switching.
- Responsive design with hover animations.
- Background gym video integration.
